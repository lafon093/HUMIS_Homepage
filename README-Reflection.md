# HUMIS Flexbox Responsive Project Reflection  

## Adv Web Design - Fall 2026 - Willow Lafontant

For this project, I found that I liked the rhythmic nature of coding these inner pages. I found the HTML side of the project to be pretty easy, especially as I've gotten the hang of the different tags and how they should be applied to the CSS styling. While styling, for me, is the more fun aspect of coding, I had a lot of trial and error for this project in order for my coding to look like the static HUMIS pages. Trying new tags and different widths, heights, margins, and paddings did help me tune my creative problem-solving skills, but it was definitely frustrating at times.  

The introduction of flexbox made coding this project easier and harder at the same time. The flexbox properties made styling the pages very easy and their attribute names made it easy to understand what each tag did and how it would affect my code. The downside is that there are a lot of flexbox properties and a lot of rules attached to each one. I do believe that I have the basics of flexbox down, and will be able to use them well in other projects. 

The concepts introduced for this project were easy to grasp and apply in the code. I learned a lot about scoping certain tags (adding class, for example), using the "&" to make CSS styling more compact, media queries, and how to more effectively divide my content in HTML to better suit my CSS. 

Overall, I believe that I had all the skills necessary in order to complete this project, and I see myself a couple of aspects in future projects. I liked the customization that we added to the active pages on the site, it was something very small, but made the website feel "real" in a sense. Additionally, flexbox, despite my hardships with it, was very useful and I will definitely will use it in future projects.
